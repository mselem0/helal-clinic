هلال — تقرير التحقق المحلي، 16 أكتوبر 2026

التنفيذ:
- الصفحات والقوائم وبيانات SEO لها مسودات ومعاينة موقعة ونشر وإلغاء واستعادة.
- الصفحات الداخلية تستخدم هوية الثيمين، وقوائم موحدة ومسار تنقل وروابط للخدمات والفروع والمقالات المرتبطة.
- تغييرات الروابط المنشورة تحفظ تحويل 301؛ الروابط العربية وحلقات التحويل ومسارات الموديولز محمية باختبارات.

التحقق:
- PHP: النسخة الأساسية 38 اختبارًا / 321 assertion، والنظام الكامل 43 اختبارًا / 340 assertion.
- توجد تحذيرات deprecation من الاعتماديات على PHP 8.5؛ لا توجد اختبارات فاشلة.
- E2E: 32 سيناريو لكل نسخة. يشمل كلا الثيمين و13 نوع صفحة على عروض 320 و390 و768 و1024 و1440.
- الاختبارات تشمل الدخول والصلاحيات والنماذج والميديا والفيديو وطلب الموعد وتعديل الصفحات والقوائم والنشر والاستعادة.
- ترقية قاعدة أساسية جديدة للنظام الكامل نجحت: مقارنة كل صف في 7 جداول محتوى قبل الترقية وبعدها، بما فيها المسودات.
- التثبيت النظيف والبناء المحلي نجحا. لم تُجر اختبارات على سيرفر أو اتصالات بتكاملات خارجية.

حدود النتائج:
- فحص SEO الآلي يراجع الجوانب التقنية؛ لا يثبت جودة المحتوى الطبي أو يضمن ترتيبًا في البحث.
- بيانات المقال والفرع المستخدمة في الفحص أمثلة اختبار داخل قاعدة مؤقتة، وليست تعديلًا على محتوى العيادة.
- الأداء وLCP معملية وتتأثر بالجهاز والخادم المحلي؛ لا تعادل Core Web Vitals الفعلية بعد النشر.
- إعدادات Apache للضغط والتخزين المؤقت لا تطبقها أداة PHP المحلية، وتحتاج التحقق على بيئة النشر المصرّح بها.
- يلزم استكمال ومراجعة بيانات الفروع والخدمات الفعلية والمقالات والمصادر قبل النشر، ثم إعداد Search Console يدويًا.
